# 서비스 및 요금제 정책

## 인증 정책

- 로그인 방식은 Google 간편 로그인만 제공한다.
- 저장, 공유 및 파일 다운로드는 로그인을 요구한다.
- 팔레트 생성은 비로그인 사용자도 횟수 제한 없이 사용할 수 있다.
- 사용자 비밀번호는 Color of Apple이 저장하거나 관리하지 않는다.
- 인증 세션은 Firebase Authentication이 관리한다.

## 무료 플랜

- 저장 프로젝트: 최대 5개
- 프로젝트 삭제 시 해당 저장 슬롯이 즉시 복구됨
- 파일 다운로드: 로그인 사용자에게 무제한
- 공유: 로그인 사용자에게 무료 제공

공유는 로그인만 요구하며 횟수 제한, 보상 조건, 만료일이 없다. 공유 데이터는 서버 문서가 아니라 URL에 포함되므로 링크를 오래 유지해도 별도의 Firestore 저장 비용이 발생하지 않는다.

`GENERATE`는 로컬 컬러 엔진으로 동작하며 사용량을 차감하지 않는다.
내보내기 코드는 화면에서 선택하거나 복사할 수 없고, 로그인 후 파일 다운로드로만 받을 수 있다. 다운로드 파일은 서버에 저장하지 않고 사용자 브라우저에서 생성하므로 Firestore 사용량 읽기·쓰기를 발생시키지 않는다.

## 퍼널 분석

Firebase Analytics에는 개인 식별 정보와 실제 HEX를 보내지 않고 다음 제품 행동만 기록한다.

- `color_picked`: 컬러피커에서 색상 선택
- `generate`: 팔레트 생성
- `palette_changed`: 팔레트 변경
- `token_edited`: 토큰 변경 및 함께 변경된 토큰 수
- `export_opened`: 내보내기 화면 진입
- `export_format_selected`: CSS, Tailwind, React Native, JSON, Figma 형식 선택
- `export_downloaded`: 실제 파일 다운로드 완료
- `project_saved`: 프로젝트 신규 저장 또는 업데이트
- `palette_shared`: 공유 링크 생성 및 복사 완료
- `user_login`: 계정 화면, 저장, 공유, 다운로드에서 로그인 완료
- `limit_reached`: 무료 프로젝트 5개 제한 도달

## Pro 플랜

예정 가격은 월 990원이며 다음 혜택을 제공할 계획이다.

- 저장 프로젝트 무제한
- 광고 제거

현재 결제 기능은 구현하지 않았다. 계정 메뉴의 플랜 업그레이드와 무료 저장 공간을 모두 사용했을 때 표시되는 Pro 안내 링크는 작업 화면을 유지하면서 Pro 비교 모달을 연다. 모달과 `/coming-soon` 페이지는 같은 예정 가격, Pro 혜택, Free·Pro 기능 비교를 보여준다. 비교표에는 두 플랜에서 동일하게 제공하는 팔레트 생성·공유·다운로드도 포함한다. 별도의 출시 안내 섹션은 표시하지 않으며, 예정 가격과 출시 상태는 가격 및 Pro 열에 표시한다.

모달의 주 CTA는 **플랜 결제하기**, 일반 버튼은 **기존 컬러북 정리하기**이다. 닫기는 우측 상단 X, 오버레이 클릭 또는 Esc로 처리한다. 결제 연동 전에는 플랜 결제하기 클릭 시 준비 중 안내만 표시하며 결제나 Pro 전환을 수행하지 않는다.

무료 계정이 저장 슬롯 5개를 모두 사용한 상태에서 새 컬러북 저장을 요청하면, 첫 모달에서 Pro의 월 990원 예정 가격과 저장 무제한·광고 제거 혜택을 Free와 비교해 바로 보여준다. 별도의 혜택 보기 단계는 없다.

- **Pro 플랜 비교**: 첫 모달에서 예정 가격과 기능 비교를 확인한다. 결제와 업그레이드는 출시 준비 중으로 표시한다.
- **기존 컬러북 정리하기**: 삭제할 컬러북을 고르고 영구 삭제 확인을 거친다. 삭제가 성공한 후에만 새 컬러북 저장 창을 다시 열며, 작성 중이던 컬러와 저장 이름을 유지한다.

슬롯 확인 이후 다른 탭에서 마지막 슬롯을 사용해 저장 트랜잭션이 한도 오류를 반환하는 경우에도 동일한 선택 모달을 연다. 기존 컬러북 수정, 생성, 공유, 다운로드에는 이 선택 모달을 띄우지 않는다. Pro 안내 링크에서 직접 컬러북을 정리하는 경우에는 새 컬러북 저장을 자동으로 시작하지 않는다.

향후 결제를 연동하기 전까지 일반 사용자를 Pro로 바꾸는 자동 경로는 없다. 테스트 또는 운영상 수동 전환이 필요하면 신뢰할 수 있는 관리자 환경에서 `users/{uid}.plan`을 `pro`로 변경한다.

## 선물 후원

홈과 작업 화면 상단의 **개발자에게 선물하기** 버튼에서 BIC 볼펜, 스타벅스 카페라떼, 빅맥 카드를 선택할 수 있다. 모바일에는 **선물하기**로 표시한다. 로그인 없이도 화면을 열 수 있다. 실제 상품을 배송하는 판매가 아니라 개발자에게 전달하는 일회성 후원이며 Pro 혜택을 부여하지 않는다.

운영자가 지정한 고정 KRW 금액은 각각 1,000원, 4,700원, 5,700원이다. 공식 상품 판매가와 자동 연동되지 않으며 `src/lib/billing/gifts.ts`에서 관리한다. 실결제 활성화 전에 수취 사업자와 후원 수납이 승인된 결제 제공자를 확정해야 한다. 선물 보내기는 현재 준비 안내만 표시한다. 결제 도입안은 [billing.md](./billing.md)를 참고한다.

## 기능별 처리

| 기능 | 비로그인 | 무료 로그인 | Pro 로그인 |
| --- | --- | --- | --- |
| 팔레트 생성 | 무제한 | 무제한 | 무제한 |
| 프로젝트 저장 | Google 로그인 요청 | 최대 5개 | 무제한 |
| 프로젝트 삭제 | 사용할 수 없음 | 가능, 슬롯 복구 | 가능 |
| 공유 | Google 로그인 요청 | 무료 | 무료 |
| 코드 복사 | 제공하지 않음 | 제공하지 않음 | 제공하지 않음 |
| 파일 다운로드 | Google 로그인 요청 | 무제한 | 무제한 |
| 광고 | 향후 정책 적용 | 노출 예정 | 제거 예정 |

## 클라이언트 복사 방지 정책

- 내보내기 코드 영역과 컬러 토큰 영역의 드래그 선택, `Ctrl/Cmd+A`, `Ctrl/Cmd+C`를 로그인 여부와 관계없이 차단한다.
- 이는 사용자 경험 수준의 방어이며 브라우저 개발자 도구나 네트워크 접근까지 막는 보안 경계는 아니다.
- 실제 권한과 사용량 제한은 Firebase Authentication 및 Firestore Rules를 기준으로 판단한다.

## 결제 도입 시 필요한 변경

1. 결제 제공자에서 월 990원 상품과 정기 구독을 생성한다.
2. 서버가 결제 웹훅의 서명을 검증한다.
3. 결제 성공·갱신·취소·환불 상태에 맞춰 Admin SDK로 `users/{uid}.plan`을 변경한다.
4. 클라이언트가 가격이나 결제 성공 여부만으로 `plan`을 변경하지 못하게 유지한다.
5. Pro 비교 모달과 `/coming-soon` 안내에 실제 결제 및 구독 관리 흐름을 연결한다.
6. 광고를 도입하면 Pro 사용자에게 광고 요청과 렌더링이 모두 생략되는지 검증한다.
