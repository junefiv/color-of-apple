# 서비스 및 요금제 정책

## 인증 정책

- 로그인 방식은 Google 간편 로그인만 제공한다.
- 저장, 공유, 팔레트 생성, 복사 및 다운로드처럼 사용자별 권한이나 사용량 확인이 필요한 기능은 로그인을 요구한다.
- 사용자 비밀번호는 Color of Apple이 저장하거나 관리하지 않는다.
- 인증 세션은 Firebase Authentication이 관리한다.

## 무료 플랜

- 저장 프로젝트: 최대 5개
- 프로젝트 삭제 시 해당 저장 슬롯이 즉시 복구됨
- 팔레트 생성: UTC 기준 12시간 구간마다 5회
- 복사 및 다운로드: UTC 기준 12시간 구간마다 합산 5회
- 공유: 로그인 사용자에게 무료 제공

복사와 다운로드는 각각 실행할 때마다 동일한 `exportCount`를 1회 차감한다. 예를 들어 같은 구간에 복사 3회와 다운로드 2회를 사용하면 내보내기 한도 5회를 모두 사용한 것이다.

팔레트 생성은 메인 화면에서 사과를 클릭하고 프라이머리 컬러를 선택한 뒤 `GENERATE`를 실행할 때 1회 차감한다.

## 12시간 한도 초기화

한도는 사용 시작 시점부터 12시간 후가 아니라 다음 UTC 고정 경계에서 초기화된다.

- 첫 번째 구간: UTC 00:00–12:00
- 두 번째 구간: UTC 12:00–24:00

한국 표준시(KST, UTC+9)로는 각각 09:00–21:00, 21:00–다음 날 09:00에 해당한다.

## Pro 플랜

예정 가격은 월 990원이며 다음 혜택을 제공할 계획이다.

- 저장 프로젝트 무제한
- 팔레트 생성 무제한
- 복사 및 다운로드 무제한
- 광고 제거

현재 결제 기능은 구현하지 않았다. 업그레이드 버튼이나 무료 한도 초과처럼 결제 또는 Pro 구독이 필요한 흐름은 `/coming-soon` 페이지로 이동한다.

향후 결제를 연동하기 전까지 일반 사용자를 Pro로 바꾸는 자동 경로는 없다. 테스트 또는 운영상 수동 전환이 필요하면 신뢰할 수 있는 관리자 환경에서 `users/{uid}.plan`을 `pro`로 변경한다.

## 기능별 처리

| 기능 | 비로그인 | 무료 로그인 | Pro 로그인 |
| --- | --- | --- | --- |
| 팔레트 생성 | Google 로그인 요청 | 구간당 5회 | 무제한 |
| 프로젝트 저장 | Google 로그인 요청 | 최대 5개 | 무제한 |
| 프로젝트 삭제 | 사용할 수 없음 | 가능, 슬롯 복구 | 가능 |
| 공유 | Google 로그인 요청 | 무료 | 무료 |
| 코드 복사 | Google 로그인 요청 | 내보내기 한도 차감 | 무제한 |
| 파일 다운로드 | Google 로그인 요청 | 내보내기 한도 차감 | 무제한 |
| 광고 | 향후 정책 적용 | 노출 예정 | 제거 예정 |

## 클라이언트 복사 방지 정책

- 로그인 및 한도 확인을 거치지 않은 코드 복사를 줄이기 위해 내보내기 코드 영역과 컬러 토큰 영역의 드래그 선택, `Ctrl/Cmd+A`, `Ctrl/Cmd+C`를 차단한다.
- 이는 사용자 경험 수준의 방어이며 브라우저 개발자 도구나 네트워크 접근까지 막는 보안 경계는 아니다.
- 실제 권한과 사용량 제한은 Firebase Authentication 및 Firestore Rules를 기준으로 판단한다.

## 결제 도입 시 필요한 변경

1. 결제 제공자에서 월 990원 상품과 정기 구독을 생성한다.
2. 서버가 결제 웹훅의 서명을 검증한다.
3. 결제 성공·갱신·취소·환불 상태에 맞춰 Admin SDK로 `users/{uid}.plan`을 변경한다.
4. 클라이언트가 가격이나 결제 성공 여부만으로 `plan`을 변경하지 못하게 유지한다.
5. `/coming-soon` 흐름을 실제 결제 및 구독 관리 화면으로 교체한다.
6. 광고를 도입하면 Pro 사용자에게 광고 요청과 렌더링이 모두 생략되는지 검증한다.
