# UI Kit source copies

The catalog starts fresh with Fold Button only. Older ink/cushion entries and their generator are removed; app/web concept previews remain separate.

Two formats: HTML + CSS (including a small inline click handler) and React (one JSX file with embedded styles). No CDN or additional package is required. Hover folds the upper-left corner. Clicking peels the button away, then restores it. Reduced-motion preferences skip the animation.

Label, size, disabled, full width and palette variants (Primary 500 by default) update preview and copied code together. The selected color is exported as a literal. Styles and keyframes use a configuration-specific scope.
